# Contributing

Thank you for your interest in improving this list. Please read this policy before opening a pull request or an issue.

## AI-generated contributions are not accepted

Pull requests and issues created by AI agents (automated bots, autonomous coding agents, LLM-generated submissions without meaningful human authorship) are **not accepted**. They will be closed without review.

## Commercial products and services

Commercial products, SaaS platforms and paid services are accepted **only after a lengthy review**. Expect such submissions to wait a long time before a decision, and there is no guarantee they will be merged.

## Open source software

Pure open source software (published under an [OSI-approved license](https://opensource.org/licenses), with a public source code repository) is reviewed and accepted reasonably fast.

## How to submit

* Add one entry per line in the right section, keeping alphabetical order.
* Use the format: `* [Name](link) - Short description`.
* Link to the project's source code repository or official website.
* Put open source and commercial software in their own subsections (`#### Open source` / `#### Commercial`) where the section has them.
